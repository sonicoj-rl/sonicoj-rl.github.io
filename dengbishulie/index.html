等比数列所有公式

系统梳理等比数列的核心定义、通项公式、求和公式及重要性质，助你快速掌握数列求值与证明技巧。

基本定义

定义与通项公式

如果一个数列从第2项起，每一项与它的前一项的比等于同一个常数，那么这个数列就叫做等比数列，这个常数叫做等比数列的公比，公比通常用字母 q 表示。

通项公式：
an = a1 · qn-1

2

核心公式汇总

通项公式变形

an · am = ap · aq (n + q = p + m)

前n项和公式 (Sn)

当公比 q ≠ 1 时：

Sn = a1(1 - qn) / (1 - q)
Sn = a1(qn - 1) / (q - 1)
Sn = (an · q - a1) / (q - 1)

当公比 q = 1 时：

Sn = n · a1

中项公式

G = √(ab) (G 为 a, b 的等比中项)
a, G, b 成等比数列 ⟺ G² = ab

倍数公式

a2 = a1 · q
a3 = a1 · q²
... an = an-1 · q
3

重要性质

下标性质

若 m + n = p + q，则 am · an = ap · aq。

项数性质

若项数为 2n，则 S2n / Sn = (a1 + a2n) / (an+1 + an) = q。

整体性质

下标成等差数列的项，仍构成等比数列。

混合性质

等比数列中，奇数项与偶数项分别构成等比数列。

S₅ = 242

常见题型

  • 已知 a₁, q, n 求 Sn
  • 已知 a₁, q, Sn 求 n
  • 已知 a₁, Sn, Sn+1 求通项
  • 等比数列与不等式结合

注意事项

1. 等比数列各项不能为0，公比 q 也不能为0。
2. 当 q = 1 时，公式 Sn = n · a1。
3. 求和公式推导通常利用错位相减法。
